# EXLONE – WhatsApp Appeal Bot

A **legitimate, safe, and Termux-friendly Python tool** that helps users generate **professional WhatsApp ban appeal messages** using **official WhatsApp support channels**.

> ⚠️ This is **NOT** an automatic unban tool.
> It does **NOT** spam WhatsApp or bypass Meta systems.
> It only helps users submit **clean, compliant appeal messages**.

---

## ✨ Features

- ✅ Python-based (runs on **Termux**)
- ✅ Supports **Temporary** and **Permanent** ban appeals
- ✅ Android & iOS appeal support
- ✅ Multiple explanation tones:
  - Formal (recommended)
  - Polite
  - Very Polite
- ✅ Auto-generated professional explanations (no user writing needed)
- ✅ Preview mode (perfect for demos, GIFs, thumbnails)
- ✅ Export appeal to **TXT file**
- ✅ Local appeal history logging
- ✅ Clean EXLONE branding

---

## 🧠 What This Tool Does

- Generates a **proper WhatsApp appeal message**
- Guides users to the **official WhatsApp support page**
- Helps avoid common mistakes that reduce appeal success
- Keeps usage **safe, respectful, and policy-compliant**

### ❌ What This Tool Does NOT Do

- ❌ Does NOT automatically unban numbers
- ❌ Does NOT spam WhatsApp support
- ❌ Does NOT guarantee unbans
- ❌ Does NOT bypass WhatsApp security systems

> Any tool claiming those features is **fake or dangerous**.
